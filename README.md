# Research Opportunity Radar
 
A web-crawling and opportunity monitoring platform for identifying:
 
- Travel grants
- Fieldwork funding
- Student awards
- Early-career researcher opportunities
- Workshops
- Summer schools
- Conferences
- Research networks
 
Current focus areas:
 
- Arctic science
- Ecology
- Marine science
- Movement ecology
- Seabirds
- Climate change
 
Built in R using:
 
- rvest
- httr2
- tidyverse
 
Status: Prototype
